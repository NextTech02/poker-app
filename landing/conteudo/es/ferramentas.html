Estas herramientas resuelven las tres cuentas que todo organizador hace antes de un torneo: cuánto dura cada nivel, cómo suben las ciegas y cuánto recibe cada puesto. Funcionan en cualquier navegador y no piden correo electrónico.

Sirven para un home game y para el torneo pequeño de un club. Cuando la operación crece, con caja, equipo y varios eventos al mes, el sistema AceBlind hace todo esto en un solo lugar.
